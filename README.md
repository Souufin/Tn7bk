# أداة تعلم الألمانية 🇩🇪

أداة ويب تفاعلية لتعلم الألمانية من الصفر — بالدارجة المغربية.

## شنو فيها
- دروس قصيرة: التحية والتعارف والأرقام
- النطق مكتوب بالحروف العربية
- بطاقات كلمات قابلة للكشف والبحث
- تمرين من 5 أسئلة بنتيجة فورية
- خدامة على الهاتف والحاسوب، وتتبع الوضع الفاتح/الداكن تلقائياً

## الاستعمال
حل `index.html` في المتصفح — بلا سيرفر، بلا تثبيت.
